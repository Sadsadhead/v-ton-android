«В ТОН» слушает инструмент через микрофон, определяет высоту звука и показывает отклонение от нужной ноты. Интернет, регистрация и внешние аудиофайлы не нужны: анализ сигнала и генерация эталонных звуков выполняются прямо на устройстве.

## Возможности

- шестиструнная гитара в стандартном строе **E–A–D–G–B–E**;
- укулеле в строе **G–C–E–A** с высокой четвёртой струной;
- автоматический поиск струны и ручной выбор;
- точные частоты при концертном строе **A4 = 440 Гц**;
- наглядная шкала отклонения в центах и быстрое сглаживание показаний;
- подтверждение после 0,7 секунды стабильного тона;
- эталонный звук каждой струны по нажатию;
- режим настройки на слух без использования микрофона;
- индикаторы фонового шума и качества сигнала;
- высококонтрастный сценический режим;
- локально синтезируемые звуки и праздничные анимации без внешних ресурсов.

## Установка на Android

1. Откройте на телефоне ссылку **[Скачать APK](https://github.com/Sadsadhead/v-ton-android/releases/latest/download/v-ton.apk)**.
2. Если Android запросит разрешение, временно разрешите браузеру или файловому менеджеру устанавливать приложения из этого источника.
3. Откройте загруженный `v-ton.apk` и нажмите **«Установить»**.
4. При первом запуске разрешите доступ к микрофону — он нужен для определения высоты звука.

> Android может предупредить, что приложение установлено не из Google Play. Это стандартное предупреждение для APK, загруженных напрямую. Сверить целостность файла можно по SHA-256 выше.

## Как пользоваться

1. Выберите **6 струн** или **укулеле**.
2. Положите телефон рядом с инструментом и сыграйте одну струну.
3. Добейтесь положения индикатора по центру: слева звук ниже цели, справа — выше.
4. Для настройки на слух включите соответствующий режим и нажимайте на струны, чтобы услышать эталонный тон.

Для более стабильного результата настраивайтесь в тихом помещении, играйте по одной открытой струне и не располагайте телефон вплотную к динамику или резонаторному отверстию.

## Сборка из исходников

Понадобятся JDK и Android SDK с API 36. В корне проекта выполните:

```bash
./gradlew assembleDebug
```

На Windows:

```powershell
.\gradlew.bat assembleDebug
```

Результат появится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Устройство проекта

```text
app/src/main/java/ru/gitarapro/tuner/MainActivity.java  интерфейс, аудио и анализ высоты
app/src/main/res/                                      тема, цвета и иконка
design/                                                исходники фирменной графики
В-ТОН.apk                                              готовый APK
```

Приложение написано на Java без сетевых библиотек. Интерфейс рисуется нативно через Canvas, а высота звука определяется локально облегчённым алгоритмом YIN.

## Приватность

Приложение запрашивает только доступ к микрофону. Запись используется во время настройки, обрабатывается на устройстве и никуда не отправляется. Разрешение на доступ к интернету в манифесте отсутствует.

## Требования

- Android 6.0 (API 23) или новее;
- микрофон;
- около 2 МБ свободного места для загрузки и установки.
